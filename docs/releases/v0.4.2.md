# Codex Monitor v0.4.2

## Changes since v0.4.1

- Condense the skill into the monitoring lifecycle and decision rules; load
  installation, SSH, subagent, native-pause and recovery details when needed.
- Replace the long MCP-wide policy with shared invariants and operation-specific
  tool descriptions. This avoids repeating the full workflow on every tool.
- Shorten callback, default-resume and skill-invocation prompts while retaining
  event routing IDs, compact/verbose labels, evidence handling and authorization.
- Compact the README into one horizontal overview with optional waiting,
  subagent and recovery diagrams inside a collapsed section. Add direct release
  downloads and links to source and validation records.
- Keep all eight tools, input/output contracts, defaults, process ownership,
  shared subagent services, SSH behavior and recovery policies compatible.

Measured against source v0.4.1 (`9209c41`), including whitespace:

| Text surface | Before | v0.4.2 | Reduction |
| --- | ---: | ---: | ---: |
| Skill entry point | 22,421 characters | 7,699 characters | 65.7% |
| MCP server instructions | 2,822 | 513 | 81.8% |
| Eight tool descriptions | 3,665 | 2,395 | 34.7% |
| Tool descriptions plus shared instructions repeated for eight tools | 26,241 | 6,499 | 75.2% |

These are character counts, not model-token or complete-conversation savings.
The final row reflects this Codex host's repeated instruction exposure; other
hosts may expose MCP instructions differently. JSON schema structures, including
required fields, defaults, ranges and enums, compare equal after excluding prose
descriptions. Detailed reference documentation remains available.

## Upgrade

Download [codex-monitor-v0.4.2.zip](https://github.com/EthenJ/codex-monitor/releases/download/v0.4.2/codex-monitor-v0.4.2.zip)
and verify its [SHA-256 checksum](https://github.com/EthenJ/codex-monitor/releases/download/v0.4.2/codex-monitor-v0.4.2.zip.sha256).
Extract the package and run:

```sh
node install.mjs
```

Reuse installation
preferences and recovery opt-outs. Finish/reconcile active monitors and pending
events before replacing an installation, reopen Codex, execute `display`, and
review the exact upgraded Stop/Interrupt hooks through `/hooks` when enabled.
