# Codex Monitor v0.2.4

## Changes since v0.2.3

- **Capacity warnings before the limit.** The plugin warns at 24 occupied slots
  and keeps the 32-observer limit. Full-capacity requests return
  `MONITOR_CAPACITY_EXCEEDED` with actionable consolidation guidance. Starting,
  stopping and muted observers count until their sensors are released; inactive
  history does not. Equivalent live registrations remain reusable at the limit.
- **Guidance for consolidating monitors.** Inspect actual source/rules, reconcile
  obsolete observers and preserve each workload's stall detection, pending
  evidence and goal-wait guards. The plugin does not merge observers or terminate
  required commands automatically.
- **Shorter wait calls.** `resume_instructions` is optional. A live wait reuses
  its current instructions; a new wait defaults to inspecting the triggering
  event and continuing the authorized task. Explicit updates remain supported.
  Goal authorization, pause ownership and the idle barrier are preserved.
- **Readable active details.** `monitor_report(details: "active")` lists active
  names, states, types and IDs. Compact mode retains its summary default; verbose
  defaults to active details. Saved state is never displayed as verified running.
- **Less duplicate reporting.** Trusted Stop/Interrupt hooks provide routine
  end-of-turn summaries. Skill, default-prompt, MCP and event guidance no longer
  require an extra report call or repeated monitor counts in the final answer.
  Operational checks, event acknowledgement and obsolete monitor cleanup remain.
- **A focused README.** Project introduction, operation and configuration replace
  accumulated release history and development instructions. The project remains
  MIT licensed.

Codex CLI 0.166.0 controls invocation JSON and hook rendering. This release
shortens inputs and provides an explicit active-detail tool result; it does not
claim a clickable hook card or an embedded graphical panel in the terminal.

## Validation

Node 24.22.0 and Codex 0.166.0: Windows passed **189/195 tests**, with six expected
platform/hardware skips; Ubuntu 24.04 passed **190/195**, with five expected
skips, running as UID 1000 with external networking disabled. Both had zero
failures. Windows used a workspace-only TEMP/TMP for isolated native installation
fixtures. Tests include capacity boundaries/concurrent creation, MCP error
propagation, active details, optional wait instructions, native goal pause/resume,
hooks and network-failure recovery. Hardware skips do not establish GPU coverage.
The production-only package installed its dependencies and passed an 11-tool
MCP smoke check, including active details, capacity and wait guards.
[Cross-platform CI](https://github.com/EthenJ/codex-monitor/actions/runs/41336997551)
passed all 18 jobs, including Node 22/24 on Windows, Ubuntu and macOS and the
isolated native network/Ubuntu suite.

## Installation

Requires Node.js **22.22+** (24 recommended), npm and Codex CLI **0.166.0+** with
a compatible local daemon. GPU monitoring additionally needs `nvidia-smi`.

Download and extract [codex-monitor-v0.2.4.zip](https://github.com/EthenJ/codex-monitor/releases/download/v0.2.4/codex-monitor-v0.2.4.zip),
then run from the directory containing `install.mjs`:

```sh
node install.mjs
```

The wizard asks for installation, display, hook and launcher preferences.
Use `node install.mjs --dry-run` to preview. Alternatively:

```sh
git clone --branch v0.2.4 --depth 1 https://github.com/EthenJ/codex-monitor.git
cd codex-monitor
node install.mjs
```

Reopen Codex after installation. Check `/plugins` and `/mcp`, and ask Codex to
execute `monitor_display`. If automatic reports are enabled, review and trust
this version's Stop/Interrupt hooks in `/hooks`. Start the launcher using the
installer's printed command if needed, and repeat after login/reboot.

For upgrades, reconcile active monitors, waits, recovery and unresolved events
before replacing the installation. Automatic conversation retries remain
separately opt-in. See the [installation guide](https://github.com/EthenJ/codex-monitor/blob/v0.2.4/codex-monitor/references/installation.md)
and the [SHA256 checksum](https://github.com/EthenJ/codex-monitor/releases/download/v0.2.4/codex-monitor-v0.2.4.zip.sha256).
