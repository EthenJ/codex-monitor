# v0.4.2 prompt review and validation

Based on `develop` at `9209c41`, synchronized with `origin/develop` on
2026-11-09. Source and deployment `main` have separate histories; deployment
files are generated from the source build rather than merging those histories.

## Prompt review

The skill now routes mode-specific detail to the existing references rather than
requiring the whole manual for ordinary monitoring. Tool descriptions own their
operation-specific decisions; server instructions retain only shared invariants.
No reference or public tool was removed.

The README now shows one five-step horizontal overview. Waiting, subagent and
recovery diagrams are short horizontal flows inside a collapsed `<details>`
section; the redundant SSH diagram was removed. Release downloads, compatibility
and validation links are grouped near the relevant sections.

| Situation | Retained decision |
| --- | --- |
| Long tests/training | Register finite observation, continue useful work, then block without agent polling. |
| Start fails or delivery is uncertain | Do not claim monitoring; use preflight and report unverified delivery. |
| Callback vs blocking result | Fetch callback evidence; reuse returned evidence; act before explicit resolution. |
| Unknown delivery or child handoff | Reconcile prior effects; never replay uncertain work. |
| Stop waiting vs stop observation | Wait cancellation preserves processes; an owned-command stop kills its tree. |
| Training completion/stall | Combine progress, PID and available GPU signals; inspect stalls and verify artifacts. |
| Child finishing while work continues | Keep observers root-owned; resolve handled events and respect branch scope. |
| Capacity pressure | Preserve workload coverage, reconcile obsolete observers, never kill required commands for slots. |
| SSH incident | Retain connection/error/expiry guards, inspect affected monitors, treat health as unknown. |
| Recovery/default changes | Preserve opt-outs and stops; explicit enabling/customization requires authorization. |
| Goal pause/input hint | Preserve manual pauses; input hints do not carry instructions or authorize goal changes. |
| Setup/reporting | Preserve preferences, refuse busy upgrades, use official hook review and no reporting wake loops. |

This is a manual decision-rule review, not a claim that a model complied with
these instructions in a paid conversation.

## Measurements and checks

The [release notes](../releases/v0.4.2.md) contain before/after character counts.
Live MCP initialization and `tools/list` were measured in a separate connection.
All eight input/output schema structures compare equal against v0.4.1 after
excluding only `description` fields. Requiredness, defaults, bounds, enums and
all other schema fields are unchanged. The server identifies itself as v0.4.2.

TypeScript compilation, both skill validators and `git diff --check` passed.
The first full run found two regressions in compact/verbose callback labels;
those labels were restored without restoring the redundant guidance. All 138
focused runtime/display/presentation cases then passed.

## Final results

- Windows, Node.js 24.22.0, Codex CLI 0.167.0, with
  `CODEX_MONITOR_TEST_NATIVE=1`: **325 passed, 18 skipped, 0 failed** across 343
  tests. The final run took about 60 seconds. Platform, SSH/container and GPU
  gates are explicit skips, not passes.
- All 138 focused runtime/display/presentation tests passed after restoring the
  callback labels; the full suite then passed with that correction.
- Production ZIP: **45 files, 30 runtime modules**, including both hidden plugin
  manifests, with no source, tests, workflows, local state or dependencies.
- Extracted ZIP: production `npm ci --omit=dev` completed with zero reported
  vulnerabilities. A fresh isolated MCP probe verified **8 tools**, executed
  `display` and read-only status, and loaded the UI resource.
- Package, lockfile (root and package entry), plugin manifest and runtime all
  report **0.4.2**. The archive has a SHA-256 sidecar.
- TypeScript unused-local/parameter checks, both skill validators, schema
  comparison and `git diff --check` passed.

No Linux/macOS host, real SSH server, GPU hardware, graphical desktop rendering
or paid-model instruction compliance was validated in this run. Existing
cross-platform results belong to v0.4.1 and are not relabeled as v0.4.2 results.

Local logs, baseline snapshots and measurement scripts are ignored artifacts
under `.tmp-v042-prompts/`. Native fixtures use isolated Codex homes and synthetic
local providers; they do not modify the installed plugin or request paid models.
