# v0.4.1 review and validation

Reviewed on 2026-11-08 on `develop`. Tests used isolated Codex homes and did not
replace the installed plugin.

## Findings and regression coverage

| Area | Correction / regression |
| --- | --- |
| Async verification and startup | Activity leases reject late reads/queued launches after completion, cancellation or disconnection; service dispatch avoids an unprotected duplicate verification. |
| Verification replacement | An old failing request cannot evict a newer subscription and interrupt its active wait. |
| Goal notifications | Initial snapshots are not stops; descendant registration reuses ancestor subscriptions; accounting is quiet while edits/budgets stop waiting, including during final reads. |
| Lifecycle | Turn IDs protect newer waits from old completion notices; ancestor closure releases descendants; parent stops cannot be bypassed by a new child poll. |
| Delivery ownership | Root/ancestor polls cannot steal a child's returned-event burst; unrelated branches keep delivering. |
| Failure recovery | Disconnect marks child delivery unknown without replay; failed delegated release persistence settles the call and holds callbacks for reconciliation. |
| Dynamic scope and guards | Recheck sources before attachment; late thread-scope sources participate, selected scope stays narrow, missing guards release waiting. |
| Member lifetime and upgrades | Retain identities through preparation/queued registration; idle and upgrade checks include delegated work; reclaim inactive members without losing provenance. |
| Scoped reports | Persist intermediate ancestor routes for hooks; compact output omits full wait instructions. |
| Shared SSH | Partition connection incidents by creator/lifetime while reusing the connection; acknowledgements remain isolated. |
| Native fixtures | Match real subscription snapshots and bound Windows SQLite cleanup retries. |

The review reproduced failing race cases before fixes. Real native runs also
exposed initial goal snapshots absent from the original fake host; the fixture
now emits them. Existing tests were extended for nested subscription replay,
and a separate regression covers stale verification failure.

The [test coverage map](../../tests/README.md) records the four removed/merged
redundant cases, remaining compatibility coverage, fixtures and environment gates.
Event eligibility is shared between event-trigger checks and handoff; unused bindings and
duplicate service verification were removed. No public tools were removed.

The cleanup Windows run exposed a 10-second timeout in the duplicate plugin
installation fixture. Its distinct cross-workspace/tool/UI assertions now run
inside the existing real wizard test after both installation and upgrade; the
second full dependency copy and plugin installation were removed.

## Validation boundaries

Skipped cases are explicit platform/hardware/container gates. Local Windows runs
real SSH server fixtures; CI also passed the separate Linux direct/ProxyJump tests.
GPU parser simulations run on both platforms and provider subprocess simulations
on Ubuntu. Real NVIDIA hardware, native macOS Codex host behavior and graphical
desktop rendering were not validated.

Native fixtures use isolated synthetic Responses providers, without paid model
requests or account credentials. They test host/tool mechanics, not model
compliance or production API availability. Uncertain handoffs require inspecting
prior effects; exactly-once external actions are not guaranteed.
